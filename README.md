#Pato Restaurant Website

A responsive Pato Restaurant website created using HTML and CSS. The project focuses on building a modern restaurant interface with multiple pages, attractive layouts, and responsive design.

#Pages

*  Home
*  About
*  Menu
*  Reservation
*  Gallery
*  Blog
*  Contact

#Technologies Used

* HTML5
* CSS3

#Features

* Responsive restaurant layout
* Sticky navigation bar
* Transparent header
* Restaurant menu section
* Image gallery
* Reservation form
* Contact section
* Hover effects
* CSS animations
* Responsive design for different screen sizes
* Multiple interconnected pages


#Objective

The main objective of this project is to practice **HTML and CSS** by creating a complete, responsive, and visually appealing restaurant website.
